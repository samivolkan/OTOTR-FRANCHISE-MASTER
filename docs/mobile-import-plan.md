## Config / Secret Rules

- Mobile apps may use only public/anon/publishable Supabase keys.
- Never put `service_role` in mobile code.
- Any existing hardcoded Supabase URL/key fallback must be moved to env/config before production.
- Master `.env.example` should include mobile public env names:
  - `EXPO_PUBLIC_OTOTR_SUPABASE_URL`
  - `EXPO_PUBLIC_OTOTR_SUPABASE_KEY`
  - `OTOTR_SUPABASE_URL`
  - `OTOTR_SUPABASE_ANON_KEY`
- Real values stay outside Git.
